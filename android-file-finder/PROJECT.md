# โปรเจกต์: แอปค้นหาข้อมูลใน Android

> ไฟล์เริ่มต้น (ข้อมูลรายละเอียดจะทยอยอัปโหลดย้อนหลัง)

- **วัตถุประสงค์:** แอป Android ค้นหาไฟล์/ข้อมูลในเครื่องโทรศัพท์
- **ฟังก์ชัน:** ค้นตามชื่อไฟล์ แบบ substring + ไม่สนพิมพ์เล็ก/ใหญ่, พิมพ์ไปเจอไป (live)
- **ผลลัพธ์:** แสดงชื่อ + path, แตะเพื่อเปิด/แชร์ไฟล์
- **สิทธิ์:** ขอสิทธิ์เข้าถึงไฟล์ทั้งเครื่องตอนเปิดครั้งแรก
- **ที่เก็บโค้ด:** `NRW-Company-/android-file-finder/`
- **Build:** GitHub Actions → debug APK (branch + draft PR, ยังไม่ merge)
- **สถานะ:** กำลังพัฒนา (session "Android file finder")
- **ที่มา:** เกิดจากตอนหาไฟล์ TTS HTML เดิมไม่เจอ

## รายละเอียดที่จะเติมภายหลัง
- สเปกหน้าจอ/UX
- โครงสร้างโค้ด
- ขั้นตอน build/ติดตั้ง APK
